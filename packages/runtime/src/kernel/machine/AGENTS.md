# Generated capability contracts

Files in this directory are generated by `pnpm contracts:generate` from the
TypeScript machine owner in the parent directory. Do not edit them manually.
They are intentionally excluded from generic formatter and line-count rules;
`pnpm contracts:check` verifies their exact bytes.

The generated set owns Policy, operation/capability/error registries,
CanonicalResource and resolution contracts, Host System and Device schemas,
Context creation, Observer/Engine capability descriptions, and shared vectors.
`node-engine-hook-capability-v1.json` comes from a real Node VM probe during
generation/check; it is not a handwritten feature claim.
