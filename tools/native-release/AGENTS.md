# Native development artifacts

This directory packages an already-built standalone `holo` binary. It owns the artifact inventory, lockfile and embedded-asset digests, reviewed engine license files, lockfile SPDX inventory, isolated Node-free execution check and archive checksum. It does not build V8, install files, sign, notarize, publish or claim complete third-party license/SBOM coverage.

`package.mjs` owns staging and cleanup; `manifest.mjs` validates binary metadata against the current checkout. Never overwrite an existing output directory. Only a newly created private staging tree may be removed on failure. Run `node --test tools/native-release/*.test.mjs`; verify the complete path using `pnpm build:native` followed by `pnpm package:native --output <new-directory>`.

`verification.json` is the last, atomically published completion marker. Its absence means an incomplete attempt, even if an archive exists. Failures retain the public output directory and any partial files; only private staging is cleaned, so concurrent user files are never recursively removed.

`archive.mjs` owns the manifest-derived USTAR member list, nofollow physical tree inventory and private-stage mode/time normalization. Archives exclude filesystem metadata and recursive discovery; verification rejects unlisted, duplicate, symlink and hardlink members. `archive.test.mjs` covers strict inventory and Darwin byte-repeatability using one prebuilt payload; this does not attest reproducible Rust/V8 builds.

`engine-gate-smoke.mjs` supplies the fixed bounded Host Policy/plugin and Guest program for archive-extracted Wasm and dynamic-import allow/deny checks. It reuses `package.mjs`'s empty-PATH runner and the delivered binary, never Node as the Runtime. The check is required before publication for both default and optional v86 archives; it is scoped Gate execution evidence, not the complete Native M4 corpus or Service acceptance. Unit tests cover fixture/terminal/cleanup contracts; actual engine behavior must also pass real packaging.

`provenance.mjs` copies the exact Cargo/pnpm/toolchain inputs into the archive, records the observed local rusty_v8 linker archive, validates the pinned upstream rusty_v8 and V8 license texts, and writes `THIRD-PARTY-NOTICES.json` plus `sbom.spdx.json`. Its lock inventory includes build-only entries and does not prove binary linkage or complete redistribution obligations. After extracting an archive, run `node tools/native-release/verify-provenance.mjs <extracted-bundle-directory>` to recheck file hashes, license records and the SPDX entries against the packaged locks.

`resolved-notice-assets.mjs` rebuilds the selected embedded JS graphs in memory and checks their bytes against generated assets and engine metadata. `resolved-notice-index.mjs` collects locked Cargo archive texts and nofollow installed npm notice leaves; it separates normal/build-path reachability and preserves missing coverage. `resolved-notice-bundle.mjs` owns exact input-hash/bundle associations, text inventory and extracted-bundle validation. The manifest envelope remains schema v1; its new provenance v2 record includes this index, and legacy provenance v1 verification remains supported. Neither an observed source graph nor a candidate license text establishes complete linkage or redistribution approval, and all release-readiness flags stay false.

The explicit Experimental v86 branch is assembled by `v86-assets.mjs` (owner-only pin, nofollow asset admission and image SPDX structure), `v86-bundle.mjs` (bundle contents), and `v86-smoke.mjs` (private cat configuration and relocated Guest check). Its embedded JS/Wasm/license copies must match the pinned installed npm package. It is not the default archive and must not claim signed release or a complete redistribution SBOM.
