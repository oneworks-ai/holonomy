# Platforms

[简体中文](../../platforms/index.md)

- [Node/Desktop](./node/index.md): separate Node child processes, restricted VM contexts, Node Inspector, and precisely authorized networking.
- [Android](./android/index.md): foreground Supervisor, multiple logical V8 runtimes, ADB devices, and native HTTP(S) provider.

The shared Runtime owns public JavaScript semantics. A platform supplies only the engine, scheduling, and explicitly authorized native capabilities.
